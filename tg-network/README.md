# tgnet – сеть Telegram-каналов на ИИ-агентах

Автономная редакция: агенты сами находят свежие новости в проверенных источниках, проверяют факты,
пишут посты в голосе канала, вычитывают их, публикуют по расписанию, модерируют комментарии,
считают просмотры, учатся на твоих правках и ошибках и предлагают «нанять» новых агентов.

Старт: два канала – **Футбол** и **Киберспорт**. Новый канал добавляется одним YAML-файлом.

---

## Как устроено

```
 Источники (RSS, официальные TG-каналы, Steam/Valve)
        │  каждые 3–10 мин
        ▼
 🛰 Скаут ── дедупликация, склейка одной новости из разных СМИ в «сюжет»   (без LLM)
        ▼
 🧠 Главред ── оценивает важность для канала 0–100, отсекает дубли и не нашу тему
        ▼
 🔎 Фактчекер ── читает полные статьи → выделяет утверждения → ищет подтверждения
        │        во ВСЕХ отслеживаемых источниках → (опц.) Google Search по белому списку доменов
        │        → вердикт по правилам, а не «на глаз» LLM
        ▼
 ✍️ Автор ── пишет пост ТОЛЬКО из факт-листа, в голосе канала, с учётом уроков
        ▼
 🧐 Выпускающий ── жёсткие автопроверки + ревью другой моделью → правки (до 2 кругов)
        ▼
 📤 Публикатор ── тебе в личку на одобрение (или сам, в режиме автопилота) → расписание
        ▼                                                       → канал
 📊 Аналитик ── просмотры/реакции → ежедневный отчёт → «плейбук» канала (что заходит)
 🎓 Учитель ── твои правки, отказы, ошибки → уроки для каждого агента
 🧑‍💼 HR ── раз в неделю: нанять/уволить агента-специалиста, добавить источник, подкрутить настройки
 🛡 Модератор ── комментарии: спам, скам, реклама, токсичность, флуд → удалить / мут / бан
 💰 Реклама ── слоты по расписанию с обязательной маркировкой (erid), формат 1/24
```

### Правдивость: как она гарантируется

Ни одному агенту не доверяют на слово, решают правила:

| Вердикт | Когда | Как публикуется |
|---|---|---|
| ✅ **confirmed** | есть официальный источник (T1) **или** ≥2 независимых крупных СМИ (T2) из разных «групп» | уверенно |
| 🟡 **reported** | одно крупное СМИ | только с атрибуцией «по данным …» |
| 🟠 **rumor** | только инсайдеры (T3) | с пометкой «Слух:», и в автопилоте всё равно через тебя |
| ⏳ **waiting** | сюжету < 3 ч и подтверждений мало | перепроверка каждые 10 минут |
| ❌ **rejected** | противоречие в источниках, устарело, нечем подтвердить | не публикуется |

Дополнительные барьеры:
- **Каждое число в посте должно буквально быть в факт-листе.** Это проверяет код, а не LLM: 2029, 50 млн, 2:1 и т.д.
- Ссылки в посте только на реальные источники сюжета.
- Подтверждение из веб-поиска засчитывается только с доменов из белого списка (`trusted_domains`).
- Автор и выпускающий работают на **разных моделях**, поэтому одна и та же ошибка у них совпадает реже.
- У каждого источника есть счёт надёжности. Источник, который часто ошибается, автоматически понижается в уровне.
- Новость старше `max_age_hours` не выйдет, даже если застряла в очереди.

### Как агенты учатся

- **Твои правки.** Нажал «✏️ Править» и прислал свой вариант. Учитель сравнивает черновик с твоей версией и формулирует 1–3 общих правила, например «не использовать эпитеты „легенда/звезда“». С этого момента правила попадают в промпт автора.
- **Отказы.** Нажал «🗑 Отклонить» и одной фразой объяснил почему. Это урок для главреда или автора.
- **Ошибки.** `/error 123 сумма была 40, а не 50`. Источники поста теряют доверие, фактчекер и выпускающий получают урок.
- **Статистика.** Каждый вечер аналитик смотрит, что набрало больше просмотров (темы, длина, время, картинки), и переписывает плейбук канала.
- **Твои правила напрямую.** `/teach football_ru writer Счёт матча всегда в первой строке`.
- Уроки, которые долго не подкрепляются, постепенно затухают. Твои правила (`/teach`) не затухают. `/lessons` показывает всё, чему агенты научились, `/forget <id>` удаляет урок.
- **Выпуск на автопилот.** Когда ≥90% из последних 30 черновиков ты одобряешь без правок, бот сам предложит включить автопилот.

### Как агенты «нанимают» агентов

**Агент-специалист** описывается декларативно, код писать не нужно: расписание, задача, какие проверенные новости канала брать. Примеры: «Итоги дня» в 22:40, «Трансферы недели», «Результаты тура».
Специалисты берутся из двух мест:
1. из YAML канала (`specialists:`);
2. от **HR-агента**. Раз в неделю (или по `/hr`) он смотрит статистику сети и предлагает нанять специалиста, уволить слабого, добавить источник или поменять настройку. Каждое предложение приходит тебе с кнопками ✅/❌ и применяется без перезапуска. При `hr_auto_approve: true` безопасные предложения применяются сами.

Специалист пишет **только из уже проверенного и опубликованного** материала, слухи не переиспользует, и его посты проходят того же выпускающего.

### Стабильность

- Каждый агент работает в отдельном цикле под присмотром супервизора. Если цикл падает, он перезапускается с паузой, остальные продолжают работать. Если цикл падает 3 раза подряд, тебе приходит сообщение.
- Очередь постов лежит в SQLite и держится на «арендах». Если процесс упал посреди шага, после перезапуска шаг повторится, ничего не потеряется и не задвоится.
- У каждой роли есть цепочка моделей: Gemini → второй провайдер → локальная модель на ноутбуке. Модель, которая отвечает с ошибками, временно отключается (circuit breaker).
- Есть дневной бюджет на LLM. Когда он исчерпан, платные модели выключаются, а модерация продолжает работать.
- Учтены лимиты Telegram (flood control, паузы между сообщениями) и битая разметка (тогда пост уходит без разметки, а не теряется).
- `/health` для Docker и uptime-мониторинга, autoheal перезапускает контейнер при зависании.
- Источник, который не отвечает, временно отключается с нарастающей паузой. После 5 сбоев подряд приходит уведомление.

## Запуск

### 1. Telegram

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи `BOT_TOKEN`.
2. Создай два канала. Добавь бота **админом** с правом публикации.
3. По желанию: группа комментариев (Настройки канала → Обсуждение). Бот там тоже админ с правами удалять сообщения и банить.
4. Напиши боту `/start`.

### 2. Сервер (VPS, Ubuntu 22.04+, 1 vCPU / 1 GB достаточно)

```bash
git clone <репозиторий> && cd <репозиторий>/tg-network
cp .env.example .env && nano .env        # токены, ключи, @каналы

# вариант А – Docker (рекомендуется)
docker compose build
docker compose run --rm tgnet python -m tgnet whoami    # узнать OWNER_CHAT_ID и id групп
docker compose run --rm tgnet python -m tgnet check     # конфиг, права бота, доступность моделей
docker compose run --rm tgnet python -m tgnet sources   # каждый источник: работает ли
docker compose up -d && docker compose logs -f

# вариант Б – без Docker
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m tgnet check && .venv/bin/python -m tgnet run   # для постоянной работы: deploy/tgnet.service
```

**Важно перед стартом:**
- Запусти `python -m tgnet sources`. Адреса RSS (особенно русскоязычных СМИ) я не мог проверить из своей среды, поэтому нерабочие поправь или выключи (`enabled: false`).
- Добавь **официальные Telegram-каналы** клубов, лиг и команд (уровень T1) в `config/sources/*.yaml`. Бери только верифицированные (ссылка с официального сайта). Шаблоны там уже лежат.
- Точные id моделей Gemini возьми в AI Studio и впиши в `.env`. `check` скажет, если имя модели неверное.
- Бэкап базы: `deploy/backup.sh` по cron.

### 3. Ноутбук (необязательно): бесплатная локальная модель

RTX 5070 Ti с 16 GB VRAM спокойно тянет модели 12–14B (Qwen3 14B, Gemma 3 12B) в 4-битной квантизации.

```bash
# на ноутбуке
ollama pull qwen3:14b
OLLAMA_HOST=0.0.0.0 ollama serve
# Tailscale на ноутбуке и VPS → в .env на VPS:
OLLAMA_BASE_URL=http://<tailscale-ip-ноутбука>:11434/v1
```

Локальная модель стоит в конце цепочки как резерв. Если ноутбук выключен, роутер её просто пропустит.

## Управление из Telegram

Черновики приходят тебе в личку: шапка (важность, вердикт проверки, источники со ссылками), под ней пост как он выйдет, кнопки **✅ В очередь · ⚡ Сейчас · ✏️ Править · 🗑 Отклонить**.

| Команда | Что делает |
|---|---|
| `/status` | конвейер каждого канала, расходы на LLM, зависшие циклы, последние ошибки |
| `/report` | отчёт за сегодня (он же приходит автоматически в 23:00) |
| `/pause [канал\|all]`, `/resume` | пауза |
| `/autopilot <канал> on\|off` | автопубликация подтверждённых новостей |
| `/teach <канал\|all> <роль> <правило>` | добавить правило агенту |
| `/lessons [канал]`, `/forget <id>` | уроки агентов |
| `/error <id> <что не так>` | разбор фактической ошибки |
| `/hr` | HR-агент сейчас предложит изменения |
| `/agents`, `/retire <имя>` | специалисты |
| `/set <канал> <параметр> <значение>` | порог главреда, интервал, лимит постов… |
| `/sources` | здоровье и надёжность источников |
| `/queue` | повторить черновики, ждущие одобрения |

## Настройка

- `config/network.yaml`: владелец, модели и цепочки фолбэков, бюджет, время отчёта и HR.
- `config/channels/*.yaml`: канал целиком: фокус, голос, формат, расписание, тихие часы, правила проверки, модерация, специалисты, рекламные слоты. Новый канал = новый файл.
- `config/sources/*.yaml`: пакеты источников с уровнями и группами независимости + белый список доменов.
- `config/prompts/<имя>.md`: положи сюда файл с именем из `tgnet/prompts/`, и он заменит встроенный промпт. Код трогать не нужно.

## Деньги и закон (РФ)

Это не юридическая консультация. Перед первой рекламой проконсультируйся с юристом.

- **Маркировка рекламы.** Каждый рекламный пост должен содержать пометку «Реклама», рекламодателя и токен erid, данные передаются в ЕРИР через ОРД. Слот без erid и рекламодателя система не опубликует.
- **Каналы от 10 000 подписчиков** нужно зарегистрировать в перечне РКН, иначе размещать рекламу в них нельзя.
- **Реклама букмекеров** разрешена только для легальных БК и с ограничениями: без обещаний выигрыша, без обращения к несовершеннолетним, 18+. Выпускающий агент блокирует «верняки», «договорняки» и подобное, список дополняется в `forbidden_phrases`.
- **Картинки** берутся из og:image источника и могут быть защищены авторским правом. Если не хочешь рисковать, поставь `images: false`.

## Ограничения (честно)

- X/Twitter, Instagram и закрытые источники напрямую не поддерживаются: их API платные или нестабильные. Можно подключить через свой [RSSHub](https://docs.rsshub.app/) как обычный `kind: rss`.
- Просмотры собираются с публичной страницы `t.me/s/<канал>`, поэтому каналу нужен публичный @username.
- Правдивость обеспечивают источники и правила. Если официальный источник сам ошибся, система тоже ошибётся, и тогда `/error` научит её осторожности.
- Один процесс на одного бота: второй экземпляр с тем же токеном получит от Telegram ошибку 409.

## Разработка

```bash
pip install -r requirements-dev.txt
pytest -q          # 50 тестов: весь конвейер, фактчек, ревью, модерация, обучение, HR, реклама, LLM-роутер
python -m tgnet once scout|editor|verifier|writer|reviewer|publisher|report   # один шаг этапа
python -m tgnet stats
```

```
tgnet/
  app.py          оркестратор, супервизор циклов, health
  control.py      пульт владельца в Telegram, роутинг апдейтов
  llm.py          Gemini + OpenAI-совместимые API, фолбэки, circuit breaker, бюджет
  telegram.py     Bot API клиент, санитайзер Telegram-HTML
  sources.py      RSS, t.me/s, Steam, извлечение статей (trafilatura)
  db.py           SQLite: очередь на арендах, уроки, метрики
  agents/         scout, editor, verifier, writer, reviewer, publisher,
                  moderator, analyst, learner, hr, specialists, ads
  prompts/        промпты агентов (на русском)
```
